# Colored Item Preset

**Class: `ColoredItemPreset`**

**Set: [Colored Item Set](/generators/sets/colored-item-set)**

### Included Presets

`ColoredItemPreset.DEFAULT`

### Creation Methods

`.create()`

Allows you to build a ColoredItemPreset from default settings.

`.createFrom(ColoredItemPreset preset)`

Allows you to build a ColoredItemPreset based off of an existing preset.
