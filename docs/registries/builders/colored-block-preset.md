# Colored Block Preset

**Class: `ColoredBlockPreset`**

**Set: [Colored Block Set](/registries/builders/colored-block-set)**

### Included Presets

`ColoredBlockPreset.DEFAULT`

`ColoredBlockPreset.WOOL`

`ColoredBlockPreset.TERRACOTTA`

`ColoredBlockPreset.CONCRETE`

`ColoredBlockPreset.CONCRETE_POWDER`

`ColoredBlockPreset.CANDLE`

### Creation Methods

`.create()`

Allows you to build a ColoredBlockPreset from default settings.

`.createFrom(ColoredBlockPreset preset)`

Allows you to build a ColoredBlockPreset based off of an existing preset.
