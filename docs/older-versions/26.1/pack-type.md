# Pack Type

**Class: `PackType`**

A simple enum class used to represent pack information when adding [Packs](/older-versions/26.1/packs).

### Values
- `OPTIONAL_RESOURCES` - *used for default-disabled resource packs which players can enable*
- `OPTIONAL_DATA` - *used for default-disabled datapacks which players can enable*
- `REQUIRED_RESOURCES` - *used for resource packs which players should not be able to disable*
- `REQUIRED_DATA` - *used for datapacks which players should not be able to disable*
